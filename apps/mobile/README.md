# apps/mobile - Aplicacion movil para empleados

Directorio reservado para la aplicacion movil (React Native + Expo).

## Estado

Pendiente de inicializacion. No se agrego `package.json` intencionalmente para
mantener el monorepo limpio hasta que comience la mision correspondiente.

## Alcance previsto

- Inicio y cierre de sesion.
- Historial personal de accesos.
- Detalle de cada evento (area, fecha, hora y resultado).

Un empleado no podra consultar el historial de otro empleado ni usar funciones
administrativas. La interfaz de usuario sera en espanol. Esta aplicacion
requiere Internet.
