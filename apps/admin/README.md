# apps/admin - Aplicacion web administrativa

Directorio reservado para la aplicacion web de administracion (React + Vite +
TypeScript).

## Estado

Pendiente de inicializacion. No se agrego `package.json` intencionalmente para
mantener el monorepo limpio hasta que comience la mision correspondiente.

## Alcance previsto

- Dashboard.
- Gestion de empleados.
- Registro y administracion de tarjetas RFID.
- Gestion de areas.
- Asignacion de permisos de acceso.
- Gestion de usuarios administrativos y roles.
- Registro y administracion de dispositivos fisicos.
- Historial general de accesos.
- Estado de sincronizacion de dispositivos.

La interfaz de usuario sera en espanol. Esta aplicacion requiere Internet.
